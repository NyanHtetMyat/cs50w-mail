# 📧 Mail

#### Video Demo:  [Here is the YouTube Link](https://youtu.be/Ldw7Q8lWbw8)


## Description
**Mail** is a Single-Page Application (SPA) built with Django on the backend and vanilla JavaScript on the frontend, this web application simulates as an email client that handles sending, receiving, archiving and replying to emails asynchronously without full page reloads.
